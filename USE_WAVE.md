### Explanation of the `./waves` Folder  
**pipline_inst**: Used to view the instructions in each stage of the pipeline after the entire system is powered on. Corresponds to `test_bolloon`  
**PS2**: Used to check the `ps2_rx` module and verify whether the received PS/2 signals are correct. Corresponds to `test_ps2`  
**KY**: Used to check whether the entire keyboard can generate the keyboard scan code data required by the AM structure. Corresponds to `test_ky`
